# あたまんなか

頭に浮かんだことを、ひとりチャットのように書き流す iOS アプリです。
書いたメモのうち「やること」になったものは、スワイプひとつでタスクにできます。
未完了のタスクは、ホーム画面のウィジェットで確認できます。

Web 版の試作(HTML/JavaScript)で使い心地を確かめてから、SwiftUI で作り直しました。

## 機能

| 画面 | できること |
|---|---|
| チャット | 画面下の入力欄から書く。本文の横に追加時刻を小さく表示する。5分以上あいたメモの間には薄い線、日付が変わると見出しを出す |
| チャット → タスク | メモを右へスワイプすると、タスクになる。元のメモには蛍光ペン風のハイライトが付く |
| タスク | 丸をタップして完了。完了したタスクは下に薄く残し、もう一度タップすると戻せる。題名をタップして編集。左へスワイプして削除し、直後は「元に戻す」を出す |
| ウィジェット | 未完了のタスクを数件と「ほか N 件」だけ表示する。タップするとタスク一覧を開く |

## 動かし方

必要なもの: Xcode 27 以降(Xcode 27.0 で確認)、iOS 18 以降、[XcodeGen](https://github.com/yonaskolb/XcodeGen)

```sh
brew install xcodegen
xcodegen generate
open Atamannaka.xcodeproj
```

実機で動かすときは、自分のチーム ID を `Configs/Local.xcconfig` に書きます(このファイルは git 管理外です)。

```
DEVELOPMENT_TEAM = ABCDE12345
```

チーム ID は Xcode の Settings → Accounts で確認できます。
Bundle ID はほかの人と重複できないため、自分で動かすときは `project.yml` の `com.yukarii` を書き換えてください。
App Group の ID(`group.com.yukarii.atamannaka`)も、`project.yml`、`SharedStore.swift`、2つの `.entitlements` で合わせて書き換えます。

テスト:

```sh
xcodebuild test -project Atamannaka.xcodeproj -scheme Atamannaka -destination 'platform=iOS Simulator,name=iPhone 18 Pro'
```

## 設計の判断

### メモとタスクを別のデータにした

タスクは、メモを指す参照を持つ別のデータ(`TaskItem`)です。メモに「タスクかどうか」の印を足す方式にはしていません。

- メモは「そのとき書いた記録」なので、タスクの題名を直しても元のメモは変えたくない
- タスクを削除してもメモは残し、ハイライトだけ外したい

この2つを素直に表せるのが、データを分ける方式でした。
削除時は SwiftData の `deleteRule: .nullify` でメモ側の参照が外れ、ハイライトも自動で消えます。

### スワイプの向きをタブの並びにそろえた

タブは左から「チャット」「タスク」の順に並べています。
メモを右へスワイプすると、タスク(右側のタブ)へ送る、という対応にしました。
タスク一覧では、iOS の標準的な操作にそろえて、左スワイプで削除にしています。
誤操作で消えないよう、全部スワイプしただけでは消さず、ボタンを押して削除します。削除の直後には「元に戻す」も出します。

### 完了はチェックの1タップだけにした

完了は、行の左の丸を押すだけです。完了したタスクは消さず、下に薄く残します。
「何を終えたか」が見えること、押し間違えてももう一度押せば戻せることを優先しました。

### ハイライトは文字の属性として付けた

メモの背景全体を塗るのではなく、`AttributedString` の背景色を使っています。
こうすると、複数行のメモでも文字のある部分にだけ色が付き、蛍光ペンで引いたような見た目になります。

### アプリとウィジェットのデータ共有

ウィジェットはアプリとは別のプロセスで動くため、そのままではアプリのデータを読めません。
そこで SwiftData の保存ファイルを App Group の共有領域に置き、両方から同じファイルを読むようにしました。

- アプリはタスクを変えるたびに、すぐ保存してから `WidgetCenter` に更新を頼む。自動保存を待つと、ウィジェットが古い内容を読むことがあるため
- ウィジェットは読むだけで、自分では定期更新しない(`policy: .never`)。変化はアプリ側からしか起きないので、無駄な更新をしないため
- App Group が使えない署名で動かした場合、アプリはアプリ専用の領域に保存して動き続ける。ウィジェットは空の一覧ではなく「アプリのデータを読めません」と表示し、原因が分かるようにしている

### 画面の行の組み立てを画面から切り離した

「5分以上あいたら線」「日付が変わったら見出し」という並びの規則は、`ChatTimeline` という純粋な関数にまとめ、SwiftUI の画面から切り離しました。
画面を動かさなくても、境界の値(ちょうど5分、4分59秒、日付をまたぐ場合)を単体テストで確かめられます。
テストには Swift Testing を使っています。

### 入力欄に案内文を出さない

「何か書かなきゃ」と構えずに書き始められるよう、入力欄は空のままにしています。
書きかけの文字は `@AppStorage` に残すので、アプリを閉じても消えません。

### プロジェクトファイルを XcodeGen で生成する

`.xcodeproj` は差分が読みにくく、手で直すと壊れやすいファイルです。
そこで、ターゲットや App Group の設定を `project.yml` に書き、そこから生成するようにしました。
すぐ開けるように、生成した `.xcodeproj` もリポジトリに含めています。
署名に使うチーム ID は、公開リポジトリに含めないよう、git 管理外の `Local.xcconfig` に分けました。

## 無料の Apple アカウントで実機に入れるときの制約

- 署名の有効期限は7日。切れたら Xcode から入れ直す
- 同時に入れておけるアプリは3つまで
- アプリとウィジェット拡張で、App ID を2つ使う
- App Group が無料アカウントで使えるかは、下の「確認の記録」に書く
